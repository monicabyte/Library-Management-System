
# Library Management System

## Project Overview
The Library Management System is a Java-based console application integrated with MySQL using JDBC. It helps manage books, track issued books, and handle book returns efficiently.

## Features
- Add new books
- View all books
- Search books by title
- Issue books to borrowers
- Return issued books
- View issued book records
- Automatically update available book quantity

## Technologies Used
- Java
- MySQL
- JDBC
- Visual Studio Code

## Database
Database Name: library_management

Tables:
- books
- issued_books

## Project Structure
- Main.java
- database.sql
- .vscode/settings.json

## How to Run
1. Install Java and MySQL.
2. Create the database using database.sql.
3. Add MySQL Connector/J to the Java project.
4. Configure your MySQL username and password locally.
5. Run Main.java.
